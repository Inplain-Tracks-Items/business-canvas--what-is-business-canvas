# What is Business Canvas

An introduction to Business Canvas and its role in production AI and Forward Deployed Engineering systems.

Part of the **Business Canvas** track on Inkplain Knowledge.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inplain-Tracks-Items/business-canvas--what-is-business-canvas.git
cd business-canvas--what-is-business-canvas
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
